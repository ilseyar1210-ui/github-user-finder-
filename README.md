## Описание

GitHub User Finder — это графическое приложение на Python (Tkinter) для поиска пользователей GitHub через официальное API, просмотра их информации и сохранения избранных пользователей в JSON.

## Как использовать API

Приложение использует **публичное GitHub API** без ключа: `https://api.github.com/users/{username}`

**Ограничения:**
- 60 запросов в час без аутентификации
- 5000 запросов в час с аутентификацией (можно добавить токен)

API возвращает: логин, имя, компанию, локацию, количество репозиториев, подписчиков, ссылку на профиль.
